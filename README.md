# 신경영상 DEVS 실험실

CT·MRI 촬영–판독 시스템의 DEVS 모델과, 조건을 바꿔 돌려보는 웹 화면.

## 실행
- Windows: `start.bat` 더블클릭 (브라우저가 열림). 또는 `python app.py` 후 http://127.0.0.1:8765
- 필요한 것: Python 3 (3.12, 3.15 에서 확인). **PyPDEVS 는 `pypdevs/` 폴더에 들어 있어 따로 설치하지 않아도 된다.**
  (PyPI 에는 없다. DEVSimPy 에 들어 있는 PyPDEVS 2.2.1 을 가져왔고 내부 import 경로 3줄만 고쳤다.)

## 화면 쓰는 법
1. 왼쪽 **실험 조건**을 바꾼다 (바뀐 칸은 파란 띠로 표시). 위의 **프리셋**에서 시작해도 된다.
   수요 곡선·촬영 슬롯·판독 근무표처럼 **시간대별 값은 가운데 "24시간 편집기"** 에서 고친다:
   줄마다 '붓' 값을 고르고 칸을 클릭/드래그해 칠한다 (Shift+클릭 = 구간 채우기). 바로 아래 **시간대별 예상 부하** 차트가 바뀌어 100%를 넘는 시간대가 보인다.
   - 가판독·최종판독·촬영 슬롯은 **자리(줄)를 추가·삭제**할 수 있다. 기본값은 Notion "명세 합친 버전"(⑦·⑧)의 값이다: CT 4·MRI 3대, 하루 CT 110·MRI 45건, 주간 촬영 슬롯 2/야간 1, 최종판독 08~16시 3명·16~24시 2명·00~08시 1명, 가판독 1자리, 7일 준비+28일 집계+3일 후속, t=0은 2024-01-01(월) 00:00.
   - 붓과 같은 값인 칸을 다시 클릭하면 **off(0)** 가 된다 (예: 붓 CT, 칸이 MRI → 클릭하면 CT → 한 번 더 클릭하면 off).
   글자 옆의 **?** 에 마우스를 올리면 그 변수·지표의 설명이 뜬다.
2. 위쪽 **▶ 실행** — 시드를 바꿔가며 5번(기본) 반복해 평균±표준편차를 낸다.
3. 먼저 **기준값 그대로** 한 번 실행해 두면 이후 실험이 기준 대비 얼마나 달라졌는지 ▲▼로 보인다.
   `≈` 는 차이가 시드 간 변동보다 작다는 뜻이다 (우연일 수 있음).
4. 실험 목록에서 체크한 것만 차트·비교표에 나온다. **지표 비교**에서는 '지표 고르기'로 여러 지표를 체크해 지표마다 차트를 볼 수 있다. 결과는 브라우저에 저장되고, JSON 으로 내보내 팀원과 주고받을 수 있다.
5. "시간대별 예상 부하(손계산)"가 100%를 넘는 시간대는 대기열이 늘어난다. 실험 전에 확인하자.

## 변수 추가하기 (`params.py`)
1. `PARAMS` 에 `_p("키", "라벨", "그룹", 기본값, ...)` 한 줄 추가
   (0~23시 시간대별 값이면 `_h(...)`. 모든 변수에는 `help=` 설명을 단다 — 화면의 ? 에 그대로 뜬다)
2. `apply_params()` 에서 그 값을 `Config` 에 연결
화면은 `/api/schema` 로 정의를 읽어 자동으로 만들어진다.

## 파일
| 파일 | 역할 |
|---|---|
| `config.py` | 기준 Config (정현 명세 값) |
| `events.py` | 이벤트 형식, 검사 요청 생성 (같은 시드 = 같은 요청·같은 서비스시간) |
| `models.py`, `system.py` | DEVS 원자모델과 Coupled 조립 |
| `analysis.py` | 지표 계산, 모델 검증 9개 |
| `experiment.py` | 한 번의 실험 실행 → KPI, 대기열 시계열 |
| `params.py` | 화면에 노출할 변수, 기본 프리셋 |
| `app.py`, `ui/index.html` | 로컬 서버와 화면 |
| `run_baseline.py` | 화면 없이 터미널에서 baseline 실행 |

## 알려진 한계
- 일별 변동은 하루 단위로 도착률에 -x~+x (건/시간) 를 균등분포로 더하는 단순한 방식이다. 요일별 배수는 모든 시간대에 곱한다. 둘 다 실제 병원 자료가 아니라 가정값이다.
- 기간은 집계 구간 최대 365일까지 쓸 수 있다. 시드 하나에 7일≈1.6초, 90일≈4초, 365일≈17초가 걸린다 (타임라인은 긴 기간에서 3~12시간 평균으로 줄여 그린다).
- 시간대는 **정시(1시간) 단위**다. 30분 단위 근무표는 못 만든다. 근무표는 매일 같은 24시간 패턴이 반복된다 (요일별 차이 없음).
- 예상 부하(손계산)는 그 시각만 본 값이라 앞 시간에 쌓인 대기열은 반영하지 못한다. 실제 대기는 시뮬레이션 결과를 볼 것.
- 이전 버전 화면(주간/야간 2단계)에서 저장한 실험은 변수 구성이 달라 새 화면에서 불러오지 않는다.
- 비용 계산은 아직 없다.
- 기본 프리셋은 명세에 직접 적힌 기준값과 수요 80/120/150%뿐이다. A·B·D 실험 조건은 팀이 정해 `＋ 내 프리셋 저장`으로 만든다.


## 명세 합친 버전 반영 (2026-11)
- **기본값 = 명세 기본값.** 바뀌지 않으며 `명세 기본값으로` 버튼으로 언제든 되돌린다. 다른 조건은 상단 `＋ 내 프리셋 저장`으로 이름을 붙여 프리셋 목록(내 프리셋)에 추가한다 (브라우저에 저장, 삭제 가능).
- 환자군 ED/IP/OP를 요청마다 부여한다(ED 24시간, IP 야간 절반, OP 평일 08~17시). 비중은 가정값. ED/IP별 촬영 후 24시간·익일 완료율과 미완료 건수를 따로 낸다.
- 가판독 대상(응급 전체 / ED 응급만 / ED·IP 응급 / 없음). 비대상 응급은 촬영 후 바로 최종판독.
- 지표 추가: P50·P90, 응급 최초 결과 시간, 촬영 완료 건수, 초과근무(시간/일), 비용.
- **비용·수입은 만원 단위, 항목을 직접 관리한다.** 맨 위 `전체 선택` 칸으로 모든 항목을 한 번에 켜고 끈다. 왼쪽 `비용·수입` 그룹에서 항목마다 체크(적용 여부)·금액 수정·✎수정·🗑삭제, `＋ 항목 추가`로 새 항목을 만든다. 항목은 구분(지출/수입), 대상(병원 고정, CT·MRI 보유/신규 증설 대수, 가동 장비·촬영 인력·판독 근무 시간, 초과근무, 촬영·판독 완료 건수), 단가 기간(시간·일·주·월·연·건당), 조건(시간대·요일·환자군·긴급도)으로 정의한다. ?설명은 항목 설정에 따라 바뀐다. `기본 항목으로`로 기본 목록 복원. 체크된 항목만 일평균 수입·지출·순이익에 들어가고, 결과 요약에 항목별 내역이 나온다. 기본 금액은 전부 가정값이다.
- 명세에 있으나 반영하지 않은 것: 검사 그룹(NEURO/BODY/MSK), 개인별 휴무·자격, 장비 점검 시간, 판독 인력 11명 풀의 날짜별 근무표.
